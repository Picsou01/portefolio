Terrain de jeu SVG

Chaque carte montre un concept. Ouvre ce fichier dans PhpStorm, lis les commentaires dans le code, modifie les valeurs et recharge la page pour voir l'effet. C'est en bidouillant les chiffres que tu vas comprendre.

1. viewBox & coordonnées

viewBox="0 0 100 100" = origine en haut à gauche, y vers le bas.

2. Formes de base

rect, circle, ellipse, line — les briques élémentaires.

3. Path — lignes

M move, L line, Z ferme le tracé.

4. Path — courbes

Q courbe quadratique, C courbe de Bézier.

5. Remplissage & contour

fill, stroke, stroke-width, opacity, stroke-dasharray.

6. Dégradés

Définis dans <defs>, appelés via url(#id).

7. Animation : pulse

Classe CSS .pulse avec @keyframes + scale.

8. Animation : rotation

Astuce : transform-origin: center pour tourner au centre.

9. Tracé qui se dessine

Technique stroke-dasharray + stroke-dashoffset.

10. Survol (CSS pur)

Passe la souris sur le cercle. Aucun JS, juste :hover.

11. Clic (JavaScript)

Clique le carré. Le JS bascule la classe .active.

12. Filtres

feGaussianBlur (flou), feTurbulence (texture organique).

13. Texte

Le texte SVG se stylise et s'anime comme une forme.

14. Mini-logo animé

Combinaison de tout : dégradé + rotation + pulse.
