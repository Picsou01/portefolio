# Portfolio E5 de Maël Davidenko.
#
# Ce site ne doit apparaitre dans aucun moteur de recherche.
#
# L'exploration des pages reste volontairement ouverte : chaque page porte
# des directives noindex, nofollow, noarchive et nosnippet, et un robot doit
# pouvoir lire la page pour en tenir compte. Fermer le parcours ici le
# rendrait aveugle a la consigne, et l'URL pourrait alors etre listee sans
# titre ni description, sur la seule foi d'un lien entrant.
#
# Le dossier des preuves, lui, est ferme : ce sont des PDF, ils ne peuvent
# porter aucune balise, et l'un d'eux est un CV nominatif. Les deux formes
# du chemin sont couvertes, avec et sans le prefixe du sous-dossier
# GitHub Pages.
#
# Les collecteurs de corpus d'entrainement sont refuses entierement : ils
# ne rendent aucun service au visiteur et ne respectent pas toujours les
# balises de page.
